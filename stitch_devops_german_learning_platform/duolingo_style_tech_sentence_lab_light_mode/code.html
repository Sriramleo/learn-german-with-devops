lightbulb German Tech Syntax Tip (Kausalsatz / Verb-End Rule)
Verb-End Position expand_more

In German subordinate clauses introduced by weil (because), the conjugated auxiliary verb (ist) gets compiled directly to the absolute end of the clause:

"... weil [der Worker-Node] [abgestürzt] [ist]."

⚡ German Verb-End Rule in Subordinate Tech Clauses: In production incident runbooks, subordinate clauses push finite actions to the end. Keep Subject first, followed by telemetry objects, with the finite auxiliary verb (ist) terminating the instruction pipeline like a closing return statement.
