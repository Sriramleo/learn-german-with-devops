Time, Deadlines & Sprint Scheduling

Zeit & Sprint-Planung
7 Phrases
Scheduling
Um wie viel Uhr treffen wir uns?
What time do we meet?
TAMIL // தமிழ்:
நாம் எந்த மணிக்கு சந்திக்கிறோம்?
#SprintRetro Rule: `um` + exact clock time
die Frist [Pl. Fristen]
die Frist einhalten
Deadline / due date (to meet the deadline).
TAMIL // தமிழ்:
கடைசி தேதி / காலக்கெடு (Dead line)
#Release Collocation: Frist verpassen / einhalten
Temporal
im Laufe des Tages
In the course of the day / later today.
TAMIL // தமிழ்:
இன்றைய நாளின் முடிவிற்குள் / பகல் வேளையில்.
#Async Genitive idiom (der Lauf -> des Tages)
Business German
zeitnah / unverzüglich
Promptly / as soon as possible (polite "ASAP").
TAMIL // தமிழ்:
விரைவில் / தாமதமின்றி (Quickly / promptly)
#PoliteUrgent Use instead of English 'ASAP'
der Termin
den Termin verschieben / ansetzen
To reschedule / set an appointment or meeting.
TAMIL // தமிழ்:
சந்திப்பை மாற்றுதல் / புதிய நேரத்தை அமைத்தல்.
#Meetings Collocation: Termin absagen/vorziehen
die Zeitzone
die Zeitzone (MEZ / MESZ)
Timezone (Central European Time / Summer Time). Crucial for DE remote teams.
TAMIL // தமிழ்:
நேர மண்டலம் (ஜெர்மனி நேரம்: MEZ / MESZ).
#RemoteWork Summer: MESZ (UTC+2) / Winter: MEZ (UTC+1)
Cut-off
bis spätestens 15:00 Uhr
By 3:00 PM at the latest (hard boundary).
TAMIL // தமிழ்:
பிற்பகல் 3:00 மணிக்கு முன்பாக / தாமதமில்லாமல்.
#SprintDeadline Rule: `spätestens` = no extension

Daily Standup & Day-to-Day Agile Phrases

Tägliches Standup & Scrum
6 Phrases
Standup: Past
Gestern habe ich an den Terraform-Modulen gearbeitet.
Yesterday I worked on the Terraform modules.
TAMIL // தமிழ்:
நேற்று நான் டெராஃபார்ம் (Terraform) தொகுதிகளில் பணிபுரிந்தேன்.
#StandupReport Grammar: `arbeiten an` + Dativ
Standup: Today
Heute werde ich den PR mergen und deployen.
Today I will merge and deploy the PR.
TAMIL // தமிழ்:
இன்று நான் இந்த PR-ஐ இணைத்து (merge) டெப்ளாய் செய்வேன்.
#CI_CD Grammar: `werden` + Infinitiv
Standup: Status
Keine Blocker meinerseits.
No blockers on my end.
TAMIL // தமிழ்:
என் தரப்பில் எந்தத் தடங்கலும் (Blockers) இல்லை.
#ClearPath Top 3 most-used standup lines
Collaboration
Ich brauche ein Review für Ticket DEVOPS-410.
I need a review for ticket DEVOPS-410.
TAMIL // தமிழ்:
எனக்கு டிக்கெட் DEVOPS-410 க்கு ஒரு மதிப்பாய்வு (Review) தேவை.
#CodeReview Rule: `brauchen` + Akkusativ
Video Call
Kannst du mich kurz entmuten?
Can you briefly unmute me? / You're on mute.
TAMIL // தமிழ்:
என்னை அன்மியூட் (unmute) செய்ய முடியுமா?
#ZoomEtiquette Denglish: entmuten / stummschalten
der Bildschirm
Ich teile kurz meinen Bildschirm.
I'll briefly share my screen.
TAMIL // தமிழ்:
நான் விரைவாக எனது திரையைப் பகிர்கிறேன் (Screen share).
#DemoTime Akkusativ masculine: `meinen Bildschirm`

Infrastruktur & Cloud
7 Terms

die Bereitstellung

பயன்பாட்டு வழங்கல் / தயாரிப்பு முறை (Deployment / Provisioning).

சேவை முடக்கம் / அமைப்பில் பிழை (Outage / Downtime).
#SRE #Incident Plural: die Ausfälle

TAMIL // தமிழ்:
முந்தைய நிலைக்கு மீட்டெடுத்தல் (Rollback / Recovery).
#DisasterRecovery English loan words often take `das`

der Engpass
Bottleneck (CPU, memory, networking, or pipeline).
TAMIL // தமிழ்:
நெரிசல் புள்ளி / செயல்திறன் தடை (Bottleneck).
#Performance Compound: `eng` (narrow) + `Pass` (pass)

TAMIL // தமிழ்:
பிழை திருத்தம் / சரிசெய்தல் (Troubleshooting / Bug fix).
#Support Verb: `Fehler beheben`
die [f]
skalieren / die Skalierbarkeit
To scale / Scalability (horizontal & vertikal).

Time Prepositions (Cheat Sheet)

The 4 golden rules for dates and sprint calendars in Germany:

um [Uhrzeit] um 10:00 Uhr Exact clock time
am [Wochentag] am Montag Days & parts of days
im [Monat/Quartal] im März / im Q3 Months & Seasons
bis [Frist] bis morgen Until / hard deadline
